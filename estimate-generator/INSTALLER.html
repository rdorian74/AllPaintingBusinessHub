🚀 Quick Setup Steps

Create Folder

Create a folder called estimate-generator on your desktop

Download Files

Click all the download buttons above and save files to your folder

Create templates Folder

Inside estimate-generator, create a folder called templates

Move index.html into the templates folder

Install Python

Go to python.org/downloads

Download and install Python 3.8 or higher

Windows: Check "Add Python to PATH" during installation!

Get API Key

Go to console.anthropic.com

Sign up → Go to API Keys → Create new key → Copy it

Install Dependencies

Windows: Open Command Prompt in your folder, run:

pip install -r requirements.txt

Mac/Linux: Open Terminal in your folder, run:

pip3 install -r requirements.txt

Set API Key

Windows:

set ANTHROPIC_API_KEY=your-key-here

Mac/Linux:

export ANTHROPIC_API_KEY='your-key-here'

Run the App

Windows:

python app.py

Mac/Linux:

python3 app.py

Open Browser

Go to: http://localhost:5000

Upload your .doc/.docx file and generate your PDF! 🎉
